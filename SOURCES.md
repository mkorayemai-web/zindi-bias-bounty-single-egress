# SOURCES.md (extra public data and documents used or cited for the Best Bias Discovery work; URL + retrieval date + licence)
Primary analysis uses ONLY the provided challenge package (Overture 2026-08-19.0 extracts, ACS B25001 housing units, strata tables). No TIGER roads,
Microsoft Building Footprints reference layer, HIFLD/USGS structures or CBP are used (challenge rule on the removed layers, forum thread 35250); the package's own Overture buildings theme is used, not the removed Microsoft reference layer.
Rows 1, 2, 5, 9 and 10 are cited documents, not primary-analysis inputs. Computed primary results in Sections 1-3 derive from rows 0, 3, 4, 6 and 8; validation facts, code benchmarks and planning-reference figures are separately attributed: row 2 supplies validation-only Table 2 facts, rows 1 and 5 benchmarks, and rows 9 and 10 context for the assumed q range, not measured occupancy.
Attribution for every table and figure derived from Overture data: (c) OpenStreetMap contributors, Overture Maps Foundation (ODbL 1.0; see row 0).
Local copies of third-party documents named below (ext/*.pdf, ext/tehama_study.txt, ext/q_sources/) are not redistributed in the repository: each row gives the URL; rows 3, 8, 9 and 10 give the sha256 of the copy used.
